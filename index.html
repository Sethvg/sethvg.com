What I work on

Senior fullstack engineer on Display & Video 360, leading projects from design through launch across the front end, the services behind it, and the storage behind those.

  • High-concurrency marketplace tooling. A bulk execution engine that attaches hundreds of curated inventory deals across dozens of campaign line items in parallel, with transactional validation and full telemetry.
  • Distributed storage migrations. Moving core backend storage onto globally distributed databases (Cloud Spanner, F1) — schema and index restructuring, DAO optimization, no user-visible disruption.
  • AI-assisted product surfaces. Generative-AI search that turns a free-form natural language query into structured inventory targeting criteria.
  • Agent infrastructure for developers. Autonomous subagents that run pre-flight validation, static analysis, code review and remote CI presubmit checks — plus MCP servers, custom functions and AI contexts the rest of the team builds on. I've given org tech talks on context engineering in Gemini CLI.
